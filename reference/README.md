# reference/ — ドット絵抽出の参考画像置き場

拠点画面のスプライト（第19弾〜）は、ここに置いた参考画像シートから抽出して作る。
チャットのアップロードはファイルが保存されない事故が起きたため、確実な受け渡し用に
このフォルダを使う。ビルド（dist）には含まれない。

## 置き方

GitHubのweb画面から：

1. ブランチを `claude/roadrace-v9-continuation-k4gspm` に切り替える
2. この `reference/` フォルダを開く
3. 「Add file」→「Upload files」で画像をドラッグ＆ドロップ
4. そのままCommit（コミットメッセージは自動のままでOK）

ファイル名は自由（例：`f_decorations.png`、`g_modular_pond.png`）。
アップロード後にチャットで一言もらえれば、こちらでpullして抽出にかける。
