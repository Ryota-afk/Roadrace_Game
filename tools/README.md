# tools/ — 開発補助スクリプト

ビルドには不要。手作業では現実的に確認できないことを機械にやらせるための道具置き場。

| ファイル | 用途 |
|---|---|
| `autoplay.mjs` | ⚠️**マイライフを自動で通しプレイし、毎月の人気度・資金・年俸・クラスを記録する。** バランスの実測（CLAUDE.md §10）はこれが無いと測れない |
| `ui_density.mjs` | 画面の情報密度（絵文字・角丸・枠線・フォント段階の数）の棚卸し |
| `verify_baseview.mjs` / `verify_radar.mjs` | 個別コンポーネントの描画確認 |
| `bike_sprites.py` / `render_bike_sheet.py` | ドット絵の抽出・シート書き出し |

## autoplay.mjs

```sh
npm run dev                                          # 別のシェルで開発サーバを起動
node tools/autoplay.mjs --port 5173 --out /tmp/ap    # 実行（40年ぶんで20〜30分かかる）
tail -f /tmp/ap/log.txt                              # 実行中でも進捗が読める
```

引数はすべて省略可（`--port` 既定 5173、`--out` 既定 `$TMPDIR/roadrace-autoplay`、
`--steps` 既定 4000）。

### ⚠️このスクリプトを直すときに壊してはいけない2点

いずれも**実際に誤った結論を出した**事故の再発防止として入っている。

1. **破壊的な操作は色で判定してブロックする。文言の列挙に戻さない。**
   確定ボタンの背景色／危険なメニュー項目の文字色が `T.color.bad` かで判定し、確認
   ダイアログでは常に「やめる」を押す。⚠️旧版は押してはいけないボタンを文言で列挙して
   いたため「ラストレースで引退」「出走する」が漏れ、**何歳でも引退してしまった**
   （第89弾。同じ漏れを3回繰り返した）。文言は増えるたびに漏れる。
2. **ショップへ寄って資金の使い道（シンク）を実際に使う。**
   ⚠️これを省いた第89弾の計測は「資金が余る」という**逆の結論**を出し、年俸上限を
   下げる判断に進みかけた（第90弾で撤回）。押せる中で常に最大額を選ぶので、
   これは「使えるだけ使う」極端側の計測である点に注意。

`T.color.action` / `T.color.bad` の実際の値を変えたら、このファイル冒頭の `ACTION` /
`BAD` 定数も同じコミットで更新すること。⚠️**主ボタンは「紫かつ全幅」で判定している**
（選択チップも同じ紫なので、色だけでは進行ボタンを特定できない）。
