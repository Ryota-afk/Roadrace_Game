## 方法

`git blame`の境界コミット（`^`＝リポジトリ履歴の最初のコミット `e45d4a6` / 2026-07-25）に
由来する行数をファイルごとに数え、「一度も触られていない割合」で並べた。
⚠️**この履歴はv39.19以降しか無い**（それ以前のv11〜v39は履歴の外）。
つまり`^`の行は「少なくとも2026-07-25以前から変わっていない＝実際にはもっと古い可能性がある」。

## ⚠️発見1：脚質ごとの「見せ場」に穴がある（5脚質中3つ）

| 脚質 | 通常コース | モニュメント（古典） | |
|---|---|---|---|
| SPR（スプリンター） | 3 | **0** | ⚠️古典が無い |
| CLM（クライマー） | 2 | 1 | ✅ |
| **RUL（ルーラー）** | **0** | 1 | ⚠️**専用コースが無い** |
| PUN（パンチャー） | 2 | 1 | ✅ |
| TT（独走屋） | 2 | **0** | ⚠️古典が無い |

⚠️**両方揃っているのはCLMとPUNだけ。** RULは第70弾で発覚済み（`FAVORS_TO_DISCIPLINE`に
`RUL`が無く、`controllers/mylife/raceStart.js`の`tmplByType`でもRULとPUNが同じ
`TEMPLATES[2]`（丘陵ロード）を共有している＝ルーラーに自分の土俵が無い）。

影響は見た目だけではない：`ACQUIRE_REQS`の`pave_sp`/`ardennes_sp`/`autumn_sp`は
モニュメントの表彰台が条件なので、**SPRとTTはこの3バッジの取得経路から構造的に外れている**。
第70弾で確立した「出走計画（地形を選ぶ）」も、RULでは機能しない。

## ⚠️発見2：グランツールが初期5コースのまま止まっている

```
春季 → クリテリウム / サーキットレース / 丘陵ロード
夏季 → 丘陵ロード   / 山岳ロード       / ヒルクライム
秋季 → 山岳ロード   / ヒルクライム     / サーキットレース
```

- ⚠️**`GRAND_TOURS`は`TEMPLATES[0]`〜`[4]`のハードコード添字**で書かれており、
  後から追加された**個人TT・ナイトクリテリウム・グラベルレース・チームTTは一度も出ない**
- 3戦の違いは実質「平坦寄り／山岳寄り／山岳寄り」だけで、⚠️**季節名以外に個性が無い**
  （夏季と秋季は山岳2種が重複している）
- ステージレースなのに**総合力を問う構成になっていない**（TTが1度も入らないため、
  現実のグランツールの根幹である「山岳とTTの二本立て」が再現されていない）
