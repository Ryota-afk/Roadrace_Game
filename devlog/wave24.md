# 第24弾：室内プロップ11種の再抽出（J/KクリーンPNG版）

**背景**：第20弾の室内プロップ11種（食堂テーブルセット・配膳カウンター・ロッカー列・
トロフィーケース・観葉植物・コルクボード自立/立てかけ・コート掛け・受付カウンター・
雑誌ラック・置き時計＝参考シートの50〜60番）は`reference/IMG_0283/0284`（jpeg写真版）
から抽出していた。2026-08にユーザーがクリーンPNG版の`reference/J.png`・`K.png`を
アップロードし（旧jpegは削除）、AskUserQuestionで「クリーン版での再抽出」を選択。

## 方針

- **セル寸法・アンカーは既存スプライトと完全一致**させる（例：cafeteriaTable 56x52
  anchor(28,51)）。`BASE_VIEW_FIXTURES`の配置座標・`pixelObjectNode`の影の自動配置が
  無変更で使え、レイアウト回帰がゼロになる。
- パレットは既存と同じ**13色/スプライト**（median cut）。

## 抽出パイプライン（今回確立した手順・5回の試行で確定）

1. **背景除去**：画像の縁から局所勾配ベースの領域拡張（隣接差≤14かつ白から≤60）。
   イラストの暗い輪郭線で必ず止まる。
2. **接地影の除去（重要）**：1.だけでは参考イラストの接地影（無彩色の薄グレー）が
   前景に残る。背景から「彩度低（チャンネル差≤14）かつ明るい（輝度140〜245）」画素へ
   第2の領域拡張を行い影を吸収する。ゲーム側が楕円影を別途描くため、焼き込み影は
   混入させない（第23弾の影修正と同じ思想）。
3. **閉じ込め純白の除去**：テーブル脚の間など、輪郭に閉じ込められて縁から到達できない
   純白（±6以内）領域は面積60px以上なら背景化。時計の文字盤など物体側の白は
   わずかに色味がある/小さいため残る。
4. **セル化**：前景境界1pxを侵食した「コア画素」から先にパレットを確定し、各セルは
   コア画素の平均色→パレットへ最近傍スナップ。充填率45%未満のセルは透明。
   - 平均だけだと輪郭線と白フリンジが混ざり泥色になる（試行1）。
   - 最頻値だけだと輪郭色のスペックルノイズが出る（試行2）。
   - **平均→パレットスナップの組み合わせが決定版**（試行3〜5）。

## 検証

- Node整合性チェック：全11種で行幅一致・legend未定義文字なし・アンカー範囲内。
- 現行スプライトとの並列比較画像で全数目視（§6：向き・シルエットが参考シートおよび
  現行と一致することを確認。配膳カウンター・受付カウンターは現行より細部が明瞭に）。
- 実ゲーム画面：解禁済みセーブ（staff4・roster12・champBest=1・classIdx=2）で
  玄関ホール・食堂・ロッカー・トロフィーの4部屋をスクリーンショット確認。pageerrorゼロ。
- `tools/verify_baseview.mjs` OK・`npm run build`成功。

抽出スクリプトはscratchpad使い捨て（手順はこのファイルに記録済み。再現する場合は
上記1〜4をそのまま実装すればよい）。
