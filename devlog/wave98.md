## 1. 引き継いだ事実（すべて再測済み）

⚠️**計測はすべて`tools/_shared.mjs`の`careerRaces()`を使った正しい年間日程**
（PRO・9年目・21レース）で取り直したもの。919判断地点。

### 1.1 2つの別問題である
| | 新人 | 円熟 |
|---|---|---|
| 症状 | 脚が尽きて何もできない | ⚠️**健全な場面なのに何も変わらない** |
| 頻度 | ⚠️**43%**（全判断700件中302件） | ⚠️**36%**（脚「十分」919地点中） |

| 選択肢間の着順差 | ⚠️**厳密に0.00** | 0.5着未満 |

### 1.2 乱数のせいではない
各選択肢を8回ずつ再走行した平均で測っても36%（1回引きの33%とほぼ一致）。
| 指標 | 値 |
|---|---|
| ①選択肢間の平均の差 | 3.35着 |
| ②同じ手のばらつき（乱数の床） | 0.80着 |
| 比（①/②） | **4.17** |
| 乱数が判断を上回る地点 | 14% |

⚠️**全体としては判断が乱数の4倍結果を動かしている＝カードは機能している。**
⚠️**問題は分布の二極化**——66%は効いているが、34〜36%は完全に等価。

### 1.3 ⚠️地形で明確に差がある（最有力の手がかり）
| 地形 | n | 等価率 | 平均の差 |
|---|---|---|---|
| **平坦** | 267 | ⚠️**46%** | 3.97着 |
| 丘 | 251 | 36% | 3.51着 |
| 登坂 | 236 | 34% | ⚠️**1.95着** |
| TT | 96 | 24% | 2.65着 |
| **スプリント** | 69 | ⚠️**23%** | ⚠️**6.16着** |

⚠️**平坦が最悪・スプリントが最良**は現実の競技の直感と一致する（平坦は集団が保たれ、
スプリントで決着する）。⚠️**登坂の平均の差が1.95着で最小**なのは意外——
山岳こそ差がつくはずが、⚠️**実際には判断で動かせる幅が最も狭い。**

## 2. 本弾の仮説（未検証）

⚠️**第96弾§7.10の`dist = groupDist`（集団内は全員同速）が平坦で最も強く効いている。**
平坦では集団が割れないので、誰が何を選んでも同じ順位に戻る。

⚠️**検証方法**：平坦区間の判断について「⚠️**選択後に集団が割れたか（solo化したか）**」と
「等価かどうか」の相関を見る。割れなかった場合に等価が集中するなら仮説は支持される。

⚠️**ただし§1.4のとおり「集団のサイズ」仮説は逆の結果が出ている。** 本仮説は
「サイズ」ではなく「⚠️**割れるかどうか**」を見る点が違うが、⚠️**本命だと思った仮説を
第97弾で3回外している**（committedBreakの因果・sendの役割・集団サイズ）ため、
⚠️**結果が出るまで判断を保留する。**
