# 第13弾：デザインの作り直し（AI臭さの除去）＋`logic/support.js`の分割

## この弾の位置づけ

第2波（§23）〜第3波（§31）で**UIテキストは何度も直してきたが、レイアウト・図形・色味という
土台には一度も手を入れていなかった**。第12弾までの改修は全部その上に載っていた。
ユーザーからの指摘：

> 今の画面のレイアウトとか図形とか色味とかってめちゃめちゃAI臭いんだよね。
> 手間をかけないで適当にやるとこのデザインになりがちだわ。
> 面倒くさがらないで、スタイリッシュなデザインやUIを目指せ。
> まず、アイコンを使うのは逃げだと思って欲しい。
> デザインは、足し算ではなく引き算です。

## 着手前の実態調査（実測）

感覚ではなく数えた。「AI臭さ」には構造的な原因がある。

### ② 「AI臭さ」の構造的な正体

| 症状 | 実測 | 何が起きているか |
|---|---|---|
| 角丸パネル | **315枚**（10px:145／12px:55／8px:38／6px:31…） | 「角丸カード」を貼るだけの単調な反復 |
| 枠線 `1px solid` | **169本** | 全部を線で囲む＝階層が無い |
| `background: C.panel` | **171箇所** | 同じ色の箱が171枚積んである |
| フォントサイズ | **30種類**。10〜13.5pxに**8段階**（10／10.5／11／11.5／12／12.5／13／13.5） | **タイポグラフィのスケールが無い**。階層を作れないから0.5px刻みで詰め込んでいる |
| アクセント色 | **6色**。hub.jsx単体で全色登場（緑29・黄27・赤8・青7・紫6・桃2） | **アクセントが6色＝アクセントが無い** |

現状の`data/theme.js`は色8個＋フォント3種のみで、**余白スケールも型階層も存在しない**。
これが「各画面が好き勝手に0.5px刻みでサイズを決める」状態を許してきた根本原因。

### ③ 対象範囲

**全52画面**（マイライフ31／シーズン・共通21）＋シーズンhub内の17小分類。
ユーザー要望は「これまで実装したもの全てに関しても考え直したい」＝全画面が対象。

## 決定事項（2026-08・ユーザー選択済み）

| 論点 | 決定 |
|---|---|
| 絵文字を撤去した後の代替 | **原則廃止＋ごく少数だけ自作の線画**。天候など「記号のほうが一覧で速い」ものだけ、統一ストローク幅の単色SVGを自作する。それ以外は撤去し、階層は級数・余白・整列・罫線で作る |
| デザインの方向 | **計器盤とエディトリアルを使い分ける**。能力値・レース結果・順位表は等幅数字＋極細罫線の「計器盤」として、監督指示・ニュース・イベントは「読み物」として組む。**1つのトークン体系の中で役割を分ける**（別々のデザインを2つ作るのではない） |

さらにユーザー指示により、**CLAUDE.md §8を新設**して以下を恒久ルール化した。
- デザインは足し算ではなく引き算
- アイコンを使うのは逃げ
- 初見の人に通じる言葉だけを使う
- **サンプル候補提示 → 選択・編集 → 合意 → 実装**の手順を省略禁止

## 進め方

```
Phase 0  A-1：logic/support.js（1,844行）の分割
         ロジック層なのでUI改修と衝突しない。先に土台を整理する
Phase 1  デザイントークンの設計 ★サンプル候補を提示して選んでいただく
         型階層／余白スケール／ニュートラル／単一アクセント／罫線の太さ
Phase 2  マイライフのホーム画面だけを新トークンで作り直す ★候補提示→編集
Phase 3  合意が取れた形を全52画面へ横展開＋絵文字653個の撤去
```

**Phase 2で1画面だけ作って見ていただくのが要**。全画面を一気に変えると、方向が外れていた
場合の損失が大きすぎる。Phase 3はPhase 2の合意が取れるまで着手しない。

第11弾の`domain/shared/scouting.js`、第12弾の`domain/season/salary.js`と切り出してきた
流れの延長で分割する。分割の内訳はPhase 0着手時に確定する。
