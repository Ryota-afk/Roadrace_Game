## フェーズ1：一覧に載せる（表示のみ・バランス変更なし）

### 並び順（ユーザー確定：候補C＋プラスの合計）

展開したスロットのリストを、⚠️**2グループ・各グループ内は「効果の大きい順」**にする。

1. **所持しているもの**
   - 装着中のパーツを**先頭に固定**
   - 残りを**プラス合計の降順**（一点物・静的パーツを混ぜて1つの並びにする）
2. **カタログ（未所持・買えるもの）**
   - **プラス合計の降順**

⚠️**見出しは置かない**（グループの区切りは並び順とボタンの文言で表現する。§8「説明文を
書く前に消す・別の見せ方を検討する」）。⚠️**`[所持]`バッジも置かない**——ボタンが
「装着する」か「28万」かで所持の有無は既に読めるため、二重になる。バッジは
`[装着中 Lv3]`だけ残す。

### プラス合計の定義

```
sortKey(p, lv) = Σ max(0, ab[k]) × (1 + ML_PART_LV_MUL * lv)
```

⚠️**マイナスは無視する**（ユーザー確定）。差し引きで並べると、尖らせたパーツ（+20/-8＝12）が
まとめたパーツ（+6×3＝18）の下に来てしまい、専門型にとっての実態と合わないため。

⚠️**Lvを掛けるのは意図的**：フェーズ2でLvがパーツごとになると、育てたパーツが上に来る
＝「今いちばん強いもの」順になる。フェーズ1の時点ではスロット内で全部同じLvなので
順序に影響しない（同じ式のままフェーズ2へ移行できる）。

⚠️**既知の限界**：`ab`が空で条件付き効果だけを持つパーツ（`nu_cool`＝冷感ボトルセット、
`heat`のみ）は`sortKey=0`で常に最下段になる。並び順は目安であって推奨ではないため
許容する。⚠️直すなら条件付き効果にも仮の重みを与える必要があり、それは別の設計判断。

### ⚠️§10の計測（この弾で必ず行う）

**測る数量**：

2. 「買うものが無くなって資金が余り始める年」の前後比較

## P2の実装記録：`builder`方策とP3比較用の基準値

`tools/simcareer.mjs`へ`builder`方策を追加した——住居・車・練習用品（ローラー／

### ⚠️実装中に見つけた自分のバグ

初回実測（n=5・20年）で恒久投資の買い切りが**0%**（1本も到達なし）という
不審な結果が出た。原因は`isFiniteSaturated()`が「5種のコーチ全員が`coachMax`に
到達」を要求していたことで、⚠️**`ML_COACH_SLOTS_BY_CLASS`（同時雇用枠1/2/3）は
5種のうち最大3人しか雇えないため、この条件は絶対に成立しないバグだった。**
正しくは「雇用枠の人数だけ雇い、雇った分は全員上限まで」に修正した（実装したその日に
自分で仕込んだバグを自分で較正で捕まえた形——第92弾のA4較正と同じ教訓の再確認）。

### 実測結果（n=5・20年、バグ修正後）

| 指標 | 実測値 |
|---|---|
| 恒久投資を買い切った本数 | **100%**（5/5・到達した年の中央値=**10年目**） |
| 実際に使った総額（最終時点・中央値） | 6,012万 |
| ⚠️**うちパーツ強化だけの額（P3比較の基準値）** | ⚠️**2,260万** |
| うちパーツ本体の額 | 92万 |
| 不変条件違反（A1〜A3） | 0件 |

⚠️**パーツ強化の実測2,260万は、第93弾でdata/から機械計算した「パーツ強化Lv5まで
×4スロット＝2,260万」と完全に一致した。** 理論値と実測値が独立した計算経路で
一致したことで、⚠️**両方の値が正しいことが相互に裏付けられた**。これが第94弾P3の
「パーツごとのLv」実装後に再測定し、比較する基準値になる。

⚠️**合計6,012万が第93弾の理論値11,720万より小さい理由**：`builder`は
成長力アップ・成長タイプ変更（合計4,600万+900万＝5,500万）を対象にしていない
（設計時に列挙した「住居・車・練習用品・コーチ・パーツ本体・パーツ強化」に
この2項目は含めていない）。11,720万−5,500万＝6,220万で、実測の6,012万と
近い値になり整合する。

### ⚠️副次的な発見：A3（資金マイナス12ヶ月連続）が実際に起きた

`builder`は3回の試行実行（n=5ずつ）で、A3の発火が2/5→1/5→0/5とばらついた。
⚠️**「押せるものを毎月すべて買う」という極端な方策のもとでは、住居・車・コーチの
維持費が積み上がって収入を上回り、赤字が12ヶ月以上続く経路が実際に成立する**
——第90弾で「シンクに注ぎ込んだ結果として破産する経路が成立しないか要確認」
（#29-e）としていた問いに、⚠️**「成立する。ただし常態ではなく、極端な投資方針の
もとで時々起きる」**という答えが出た。⚠️`month.js`の赤字ペナルティ（`debtMonths`≥4で
