## 実測：⚠️「0と0」はデビュー戦だけの話ではなかった

キャリア開始から26レース連続の`resultInfo`：

| # | 年/月 | 着順 | pts | 賞金 | 予想 | 世界ランク(前回) | 監督指示 |
|---|---|---|---|---|---|---|---|
| 1 | 1/0 | 36/43 | **0** | **0** | 43番手 | 21(—) | 達成 |
| 2 | 1/1 | 29/44 | **0** | **0** | 31番手 | 135(21) | 未達 |
| 3 | 1/2 | 25/38 | **0** | **0** | 38番手 | 160(135) | 未達 |
| … | … | … | **0** | **0** | … | 22x台 | 達成/未達が半々 |
| 25 | 3/0 | 29/44 | **0** | **0** | 10番手 | 232(231) | 未達 |
| **26** | **3/1** | **4/42** | **6** | **12万円** | 9番手 | 219(232) | 達成 |

⚠️**26レース中25レースが「獲得ポイント +0pt」「賞金 +0万円」。**
初めて0でなくなるのは**26レース目＝3年目2月**（4位）だった。

### 構造的な原因

`data/economy.js`：

```
export const PRIZES = [100, 60, 40, 30, 22, 16, 12, 9, 6, 4];
export const PTS    = [ 10,  7,  5,  3,  3,  1,  1, 1, 1, 1];
```

どちらも⚠️**10要素の配列＝11位以下は一律ゼロ**。
新人のB1での着順帯は本計測で14〜44位（26戦中、10位以内は1回だけ）。

⚠️**計測の限界（明示）**：この方策は毎月必ずレースに出て**練習を一度もしない**
（`tools/simcareer.mjs`の既定方策と同じ）。難易度は**easy**
（`initMyLife()`が`mlDiffChoice`を持たないため`createChar`が`"easy"`へ倒れる）。
実プレイヤーは練習するのでゼロを抜ける時期は早まる。⚠️**「25戦ゼロ」はこの方策での値。
ただし「11位以下は一律ゼロ」という構造自体は方策に依存しない。**

`beatForecast = forecast && rank < forecast.rank - 1`（`race.jsx:198`）。

## 実測3：⚠️色の割り当てが逆になっている

デビュー戦の結果画面で、

| 行 | 出現頻度 | 実際の色 |
|---|---|---|
| 「予想を上回る快走」 | **92%（ほぼ毎回）** | ⚠️**good（緑）** |
| 「初めてランキングに載った」 | **キャリアで1回だけ** | ⚠️**sub（灰）** |

`worldRankUp = worldRank != null && worldRankPrev != null && worldRank < worldRankPrev`
——初掲載は`worldRankPrev == null`なので`worldRankUp`が`false`になり、
⚠️**一度きりの出来事が「上昇でも下降でもない」灰色で描かれる**。

## 実測4：⚠️世界ランキングは最初の2年ほぼ毎回「後退」

21位（初掲載）→ 135 → 160 → 223 と**4戦で急落**し、以後2年間222〜232を漂う。
26戦目（4位）でようやく232→219へ上がる。

つまり⚠️**「世界ランキング」の行は、最初の2年間ほぼ毎回「◯位から後退」を出し続ける。**
（初掲載時に21位という高い数字が出るのは、その時点でランキングに載っている母数が
少ないため。プレイヤーから見ると「21位でデビュー→すぐ223位に転落」と読める。）

## 実測5：⚠️「この一戦の成果」に他人の記録が入る

`courseRecord`は`isNew`だけで出し分けており、`isPlayer`は色と文言にしか使っていない。
実測では#1が「牧野 奏太が樹立」、#26が「松井 遼が樹立」——
⚠️**どちらも他人の樹立が「あなたの成果」欄に並んでいる。**

## この弾で分かったことの意味

⚠️**最初の2年間、「この一戦の成果」で情報を持っている行は「監督指示の達成/未達」だけ**である
（26戦で達成12・未達14とほぼ半々＝実際に分岐している）。他は、

- 獲得ポイント／賞金＝**常に0**
- 予想超え＝**92%で出る**
- 人気度＝**毎回 +0.1〜0.2**
- 世界ランキング＝**ほぼ毎回「後退」**
- コースレコード＝**他人の記録**

⚠️**したがって「表示の作り直し」だけでできることには天井がある。**
並べ替えても、2年間ゼロであるという事実は変わらない。
これは表示の問題と**報酬設計の問題**（11位以下に何も無い）が重なっている。

⚠️**報酬設計に手を入れるのはバランス変更であり、§10の計測を伴う別の判断である。**
本弾では勝手に広げず、ユーザーに提示して選んでもらう。
