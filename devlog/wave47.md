# 第47弾（設計確定）: バッジと体質を分ける

## 発端：第44弾の「はずす」が2種類の壊れ方をしていた

第46弾の完了後の棚卸しで、`r.abilities`には**性質の違う2種類**が同居していると判明した。
第44弾はこれを一律に「無料で付け替えられる装備スロット」として扱ったため、同じ
「はずす」ボタンが対象によって3通りの結果になっていた。

| 区分 | 種数 | 「はずす」を押すと |
|---|---|---|
| 実績で獲得する（`ACQUIRE_REQS`あり） | 24 | 正常。いつでも付け直せる |
| 体質系（経路なし） | 10 | ⚠️**永久に失われる**（`天才肌`等） |
| 悪特性 | 6 | ⚠️**無料で除去できてしまう**（`ガラスの体``練習嫌い`等） |
| 配合限定 | 8 | ⚠️**永久に失われる**（`絶対王者の血`等の血脈レシピ最上位） |

`mlAcquireAbility`は`ACQUIRE_CONDITIONS`に無いidを弾くため、付け直しが構造的に不可能。
第44弾のコメントにある「外しても累積実績は保持されいつでも戻せる」は、24種にだけ成立し、
残り24種には成立していなかった。

**露出（実測・生成20,000人）**
- 体質系を1つ以上持つ選手：**20.6%**
- 悪特性を1つ以上持つ選手：**17.9%**
- ⚠️**大学卒の経歴perkは`genius_sp`（天才肌）＝体質系**。3つの経歴のうち1つを選ぶと
  100%が「消えうる特能」を持って始まる（`data/events.js`の`ML_BACKGROUNDS`）。
- 平均**0.41枠**が「はずせないはずのもの」に食われている。

## 確定仕様

### 分類（`ACQUIRE_REQS`の有無で機械的に割れる。24／24）

- **バッジ**＝`ACQUIRE_REQS[id]`が存在する24種。付ける／はずすが可能。**枠を消費する**。
- **体質**＝上記以外で`ABILITIES[id].breedOnly`でない16種（体質系10＋悪特性6）。
  付け外し不可。**枠を消費しない**。
- **血脈**＝`ABILITIES[id].breedOnly`の8種。付け外し不可。**枠を消費しない**。

判定ヘルパーは`domain/mylife/cp.js`に置く（`ACQUIRE_REQS`の所在に合わせる。
`core/core.js`へは置かない——依存の向きが`core → domain`にならないようにするため）。

### 画面（案2＝3節構造・ユーザー選択）

モックで3案（2節／3節／1節のまま）を実フォント・実トークン・実データで比較した結果、
**案2（3節）**に決定。案3（1節のまま・ボタンを出さないだけ）は、描いてみると体質の行だけ
マークもボタンも無く「まだ段階が上がっていないバッジ」に見えてしまい、なぜその行だけ
操作できないのかが画面から読み取れないため却下した。

```
使用中のバッジ                        残り2枠
 ◆ 山の申し子      山岳・山頂フィニッシュ区間で能力+4
                   虹まで 7 / 10勝  ▓▓▓▓▓▓▓░░░
 ◇ 岳人           丘陵・登坂・山岳の全区間で能力+4
                   銀まで 18 / 25回  ▓▓▓▓▓▓▓░░░
 ◆ 献身のアシスト   牽引中の能力+3     金まで 7 / 8回
 （空き）
 （空き）

体質                            生まれつき・変更できません
   天才肌          25歳以下の練習・出走経験の伸びが+15%
   ガラスの体       脆い体。…                      ← T.color.bad

血脈                              配合で受け継いだ力
   絶対王者の血      全能力+6。あらゆる地形で能力+5、エネルギー消耗-8%
```

- 体質・血脈の行は**段階マークもボタンも出さない**（段階の概念自体が無いため）。
- ラベルは`paddingLeft:18`でバッジ節の説明文と左端を揃える。
- 体質節の並び順は「良い体質 → 悪特性」。悪特性は`T.color.bad`（既存の作法どおり）。

### empty state

- **体質節**：該当0件なら節ごと非表示。
- **血脈節**：該当0件なら節ごと非表示＝**通常キャラでは常に出ない**（配合キャラ専用）。
- **使用中のバッジ節**：従来どおり0件でも（空き）だけを並べて必ず出す（第44弾の方針）。

### 枠（ユーザー選択：消費しない）

`mlBadgeSlots`（B1:3／A:4／PRO:5）自体は変更しない。**数える対象だけ**が
「`r.abilities`の全件」から「そのうちバッジ24種だけ」に変わる。

⚠️**バランスへの影響（実測・合意済みだが要観察）**

| | 影響 |
|---|---|
| 通常生成キャラ | 64.7%は影響なし／29.6%が+1枠／5.3%が+2枠／0.4%が+3枠（平均+0.41枠） |
| 配合キャラ | `breed.exclusive`は最大3種（`sireline`/`hybrid`/`dynasty`）＋血脈レシピ分。 
  継承特能が枠を食わなくなるため**最大+5枠**になりうる |

配合エンドゲームが強くなる方向の変更である点は明示的に受け入れる。ただし
「悪特性を引いた選手が枠まで失う二重の罰」を消すことが主目的であり、そちらの効果の方が
プレイ体験への寄与は大きいと判断した。

## 変更箇所（全列挙）

**`src/domain/mylife/cp.js`**
1. 新規`mlBadgeKind(id)` → `"badge" | "taishitsu" | "ketsumyaku"`（上の分類定義そのまま）。
2. `mlAcquireAbility(r, id, swapOutId, maxSlots)`：枠の判定を
   `abilities.length < maxSlots` から**バッジ24種だけを数えた件数**へ変更。
   入れ替え（`swapOutId`）も**バッジ以外は対象にしない**。
3. `mlUnequipAbility(r, id)`：バッジ以外が渡されたら**何もせず`r`を返す**
   （UIが出さない前提だが、防御として関数側でも塞ぐ）。
4. `acquireNewAbility(r)`（シーズン側）：`abilities.length >= 3`も同じ数え方のバグ。
   バッジ24種だけを数えるよう揃える。⚠️第39弾で「シーズンは据え置き」と決めた対象だが、
   これは仕様変更ではなく**同一の数え間違いの修正**なので今回まとめて直す。

**`src/screens/mylife/rider.jsx`**
5. `heldRows`をバッジ24種だけに絞る。
6. `full` / `remaining` をバッジ件数基準へ。
7. 入れ替えパネル（現行174行目付近）の候補一覧を**バッジだけ**に絞る
   （⚠️ここも悪特性を外して踏み倒せる経路になっている。「はずす」ボタンと両方塞ぐ）。
8. 「体質」節・「血脈」節を新設（上記の見出し・補足・並び順・empty stateどおり）。

**`src/components/panels.jsx`**
9. `TraitLine`の`（金は効果2倍）`という文言。第45弾で4段階（銅/銀/金/虹）にした結果、
   金が2倍なのは一部の種だけで正しくない（例：`engine`は0.88→0.80、`bigheart`は
   1.07→1.10）。`create.jsx`とシーズンの選手一覧で今も表示されている。文言を削るか
   実態に合わせる（§7：伝わらない説明は足さない）。

## 検証項目

1. 体質・悪特性・血脈が**はずせない**こと（ボタンが出ない・関数を直接叩いても変化しない）。
2. 入れ替えパネルの候補にバッジ以外が**出ない**こと（踏み倒し経路の封鎖）。
3. 枠の残数が**バッジだけ**で数えられていること（悪特性3つ持ちのPROで「残り4枠」）。
4. 体質0件・血脈0件のキャラで、それぞれの節が**出ない**こと。
5. 大学卒（`天才肌`持ち）で新規開始し、体質節に出て、はずせないこと。
6. 配合キャラで血脈節が出ること。
7. 旧セーブ（`abilities`に体質が混ざったもの）を読み込んで、枠数が正しく再計算されること。
8. `pageerror`ゼロ・**縦線ゼロ**（§8）・**絵文字ゼロ**（§8）。
