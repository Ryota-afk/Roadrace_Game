# 設計差分メモ v3→v4（Unity実装用）

## 1. バグ修正・3D演出強化

- **車輪の向き修正**：TorusGeometryをY軸90度回転し、進行方向に整列
- **トレイン隊形**：チームごとにレーンを割り当て、チーム内は縦一列（エースは最後尾＝風よけ位置）。区間タイムの差が開くと自然に隊列が崩れる
- **戦術実況**：初期戦術に応じた実況（逃げ＝スタート直後に飛び出し宣言／山岳アタック＝最初の登りでエース名をコール／集団待機＝最終区間で「トレイン発射」）

## 2. 3D観戦中の戦術変更（無線システム）

- 観戦画面に📻ボタン3種を常設。タップで即時に作戦変更
- **実装方式：未走行区間のみ再計算**。各選手について現在走行中の区間を特定し、次区間以降の区間タイムだけを新戦術で計算し直す。走行済み・走行中の区間は保持するため、画面上の位置は連続を保つ
- 疲労蓄積は戦術非依存のため、区間0から決定論的に再構築可能
- Unity実装メモ：`RaceSimulation`グラフに `RecomputeFrom(riderId, segIndex, tactic)` サブグラフを追加するだけで対応可能。**区間タイム方式だからこそリアルタイム介入が低コストで実現できる**ことの実証

## 3. スポンサー契約

- 年度頭（4月前）に3社からオファー：**安定型**（高月額・低ノルマ・低ボーナス）／**バランス型**／**挑戦型**（低月額・高ノルマ・高ボーナス）
- 毎月の契約金が自動入金。年度末にシーズンポイントがノルマ以上ならボーナス
- 金額はクラスに比例してスケール。リスク選好をプレイヤーに委ねる設計（ウイポの馬主契約・サカつくのスポンサーと同型）

## 4. 特性スキル（6種・所持率30%）

| 特性 | 効果 | 実装レイヤー |
|---|---|---|
| 大舞台に強い | ★3レースで全能力+6% | 実効能力計算（ビルド時に乗算） |
| 逃げ屋 | 「逃げ」戦術の効果1.5倍 | 区間タイム計算（ランタイム） |
| 山の申し子 | 登坂系区間で能力+4 | 区間タイム計算（ランタイム） |
| 鉄人 | 出走疲労 +45→+32 | 月次処理 |
| 回復力 | 毎月さらに疲労-15 | 月次処理 |
| 勝負師 | 最終区間で能力+5% | 区間タイム計算（ランタイム） |

初期ロースター：佐伯＝勝負師、高梨＝山の申し子、燕＝鉄人（連闘ルールとのシナジー枠）。

## 5. クラス連動の解禁構造

- **パーツにtier**を設定：tier1＝B1から／tier2＝Aで解禁（+10級）／tier3＝PROで解禁（Ultimate：全能力+4等）。未解禁は🔒表示
- **チーム機材のLv上限**：B1=3／A=4／PRO=5（コスト：40/70/110/160/220万）

## 6. スカウト方針と育成調整

- **3月にスカウト方針を選択**（おまかせ/スプリント重視/登坂重視/将来性重視/即戦力重視）→ 4月の候補**5名**の生成に反映（タイプ・年齢帯・成長力分布・現在値をバイアス）
- **練習指定外の能力も微成長**：指定能力の20%で全能力が伸びる
